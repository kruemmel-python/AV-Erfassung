AV-Erfassung – Teamleiter-Keygenerator
======================================

1. Starten Sie „Teamleiter-Keygenerator starten.bat“ auf einem geschützten
   Teamleiter-PC.
2. Klicken Sie bei Bedarf auf „NEUEN KEY ERSTELLEN“.
3. Kopieren Sie den Key und geben Sie ihn in der App unter
   „TEAMLEITER: KISTE BEARBEITEN“ ein.
4. Jeder Key ist ab seiner Erstellung genau neun Stunden gültig.

WICHTIG: Der gesamte Ordner Keygenerator muss ausschließlich für berechtigte
Teamleiter zugänglich sein. Die Mitarbeiter benötigen nur die Android-APK.

Alternativ steht im Projektstamm die eigenständige Android-App
„Teamleiter-Keygenerator-release.apk“ zur Verfügung. Auch diese APK darf nur
an berechtigte Teamleiter verteilt werden.
