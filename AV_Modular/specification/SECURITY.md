# AVM Security Policy

Sicherheitsmeldungen werden vertraulich an `ralf.kruemmel@outlook.de` gesendet. Eine Meldung SHOULD Produktversion, reproduzierbare Auswirkung und betroffenen Vertrag enthalten, aber keine realen Personal- oder Prozessdaten.

Bei Schlüsselverlust MUST der Betreiber den Schlüssel sperren, betroffene Paket- und Backup-IDs bestimmen, eine neue Schlüsselgeneration bereitstellen, Artefakte neu signieren, über MDM neu verteilen, die Installation bestätigen und einen Audit- und Incident-Bericht erzeugen. Kompromittierte Schlüssel dürfen nicht wieder aktiviert werden.

Unterstützt werden die jeweils in `COMPATIBILITY.md` genannten Hauptversionen. Schwachstellen werden koordiniert behoben; Vertragsänderungen folgen AVM-EP.
